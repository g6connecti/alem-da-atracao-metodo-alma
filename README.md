# Além da Atração — Método ALMA

Protótipo web local da jornada de 21 dias, com exercícios de reflexão e vídeos guiados do Dia 1.

## Arquivos principais

- `alem-da-atracao-metodo-alma.html` — página principal do projeto.
- `alma-dia01-bloco01.mp4` — vídeo do Bloco 1.
- `alma-dia01-bloco02.mp4` — vídeo do Bloco 2.
- `alma-dia01-bloco03.mp4` — vídeo do Bloco 3.

## Executar localmente

Mantenha o arquivo HTML e os três vídeos na mesma pasta e abra `alem-da-atracao-metodo-alma.html` no Chrome ou Edge.

Os caminhos dos vídeos são relativos. Para evitar que os vídeos deixem de funcionar, mantenha os nomes dos arquivos e a localização conforme indicado acima.

## Segurança

- Não envie senhas, tokens de acesso, chaves de API, arquivos `.env` ou credenciais para o repositório.
- O projeto está em desenvolvimento. Antes de publicar o site, revise os conteúdos e os direitos de uso dos recursos de mídia.
- O protótipo atual usa armazenamento local do navegador para alguns dados; não possui ainda autenticação nem sincronização entre dispositivos.

## Publicação

O projeto pode ser avaliado para publicação como site estático. Como os vídeos são grandes, verifique os limites de upload do GitHub e considere hospedar os vídeos separadamente ou usar Git LFS antes de adicionar todos os vídeos ao repositório.
